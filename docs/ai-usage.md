# Personal AI Usage Rules — Module 5

## 1. What I will never paste
I will never paste real student answers to instructor course evaluations or any other surveys, like student satisfaction surveys or exit surveys, into any AI tool. I will also never paste login credentials. This applies even to small excerpts, since survey comments can be identifying in context.

## 2. What I will always verify before accepting
Before accepting AI-generated code or review findings, I will trace the relevant code line by line and explain its checks in my own words. I will not assume an AI review is complete - I will inspect the relevant code myself for issues the AI missed, since my own manual scan has caught real problems AI overlooked (e.g., the `reload=True` issue).

## 3. How I will record AI contributions
I will record every AI contribution by naming the specific artifact or finding received - for example, models, validators, routes, tests, documentation rewrites, or security findings -in the relevant docs/ file for that module (e.g., security-review.md, governance-worksheet.md).
